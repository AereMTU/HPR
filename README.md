# HPR Repository

This repository contains the source, documentation, and reference materials for AERE's High Powered Rocketry project. It is organized around embedded firmware software development as well as resources for development, including legacy IREC content and previous data.

## Repository structure

- [Firmware](./Firmware) - active embedded software and development documentation
  - [Firmware README](./Firmware/README.md)
  - [Getting Started](./Firmware/getting-started.md)
- [IREC_2027](./IREC_2027) - materials related to the 2027 IREC competition work and avionics planning
- [Legacy](./Legacy) - older or experimental code retained for reference; not the primary active build

## Purpose

The project focuses on avionics and flight-control electronics for a high-power rocket platform. The most relevant development work lives under [Firmware](./Firmware), while the other folders contain supporting documentation or archived iterations of the system.

## Notes

- Use the firmware folder for current design and development work.
- The legacy folder is useful for understanding earlier approaches, but it should not be treated as the current baseline.
- For setup and environment details, start with [Firmware/getting-started.md](./Firmware/getting-started.md).
